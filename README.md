# 📝 BRP Todo: The Bro-Mode Task Manager

> **The cleanest, most efficient Todo app built for the grinders.**  
Whether you're pushing pixels as a UI/UX designer or shipping code as a developer, **BRP Todo** keeps your workflow tight and your vibes high. Stop overcomplicating your day—open, add, and crush your tasks. 🚀

[![Download Latest Release](https://img.shields.io/badge/Download-Android%20%26%20iOS-2ea44f?style=for-the-badge&logo=github)](https://github.com/MichaelCode-tech/Todo-app/releases)

---

## ⚡ Key Features

* 🚀 **Insane Speed:** Built with Flutter + Isar/Hive for near-instant local persistence.
* 📌 **Stay Focused:** Pin your top-tier tasks to the top of your stack.
* 🎨 **Vibe Check:** Switch seamlessly between **Modern** and **Retro (8-Bit)** UI themes.
* 🌙 **Dark Mode:** Standard equipment for the 2 AM coding grind.

## 🛠️ Local Setup & Development

Want to run the project locally or contribute? Follow these steps:

```bash
# 1. Clone the repository
git clone https://github.com/MichaelCode-tech/BRP-Todo/

# 2. Change into project directory
cd Todo-app

# 3. Get dependencies
flutter pub get

# 4. Run the app
flutter run
